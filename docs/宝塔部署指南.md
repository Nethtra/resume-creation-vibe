# 手动部署指南 · 宝塔面板（阿里云 2C2G · 香港节点）

> 目标地址：`https://resume-creation.wtyw.asia`
> 项目性质：**纯静态 SPA**——构建产物只有 HTML/JS/CSS/字体文件，没有后端、没有数据库、不需要 Node 常驻进程。
> 服务器只需做一件事：用 Nginx 托管静态文件 + 一条「前端路由回退」规则。
> 域名 `wtyw.asia`，服务器在香港，**无需 ICP 备案**。

---

## 0. 部署思路（30 秒看懂）

```
你的 Windows 电脑                          阿里云服务器（2C2G + 宝塔）
npm run build  →  dist/ 目录  ──上传──▶  /www/wwwroot/resume-creation.wtyw.asia/
                                            Nginx 托管静态文件
                                            伪静态规则处理 /editor 刷新
```

**为什么不在服务器上构建？** 2G 内存跑 Vite + TypeScript 编译很吃力（Node 构建峰值可吃 1.5G+），容易 OOM 卡死。
正确姿势：**本地构建、上传产物**。构建产物是完全确定的静态文件，在哪构建都一样。

---

## 1. 前置准备

1. **安全组放行端口**（两处都要确认）：
   - 阿里云控制台 → ECS → 安全组 → 入方向规则放行 **80（HTTP）和 443（HTTPS）**；
   - 宝塔面板 → 安全 → 防火墙同样放行 80 / 443。
2. **DNS 解析**：到 `wtyw.asia` 的 DNS 管理处添加一条记录：
   - 记录类型 `A`，主机记录 `resume-creation`，记录值 = 服务器公网 IP，TTL 默认。
3. **验证解析生效**（本机 Git Bash 执行）：

   ```bash
   ping resume-creation.wtyw.asia
   ```

   返回的 IP 是你的服务器即生效（新记录一般几分钟内生效）。

## 2. 本地构建（Windows / Git Bash）

```bash
cd /d/code/resume-creation
npm run build
```

构建成功的标志：末尾输出 `✓ built in ...`。产物在 `dist/` 目录，关键内容：

| 内容 | 说明 |
|---|---|
| `index.html` | 入口（已含全部 SEO meta 与结构化数据） |
| `assets/` | JS/CSS（文件名带内容 hash，可永久缓存） |
| `fonts/` | 13 个中文字体子集，约 38MB（PDF 导出用，**必须完整上传**） |
| `robots.txt` / `sitemap.xml` / `og-image.png` | SEO/GEO 文件 |

> 提示：`npm run build` 自带 `tsc --noEmit` 类型检查，报错先修类型再部署。

## 3. 宝塔添加站点

新版宝塔（阿里云定制版）的「网站」页顶部有项目类型 Tab：PHP项目 / Java项目 / Node项目 / … / **HTML项目**。本项目是纯静态站，**选「HTML项目」Tab → 添加站点**：

1. 域名：`resume-creation.wtyw.asia`
2. 根目录：默认即可（`/www/wwwroot/resume-creation.wtyw.asia`）
3. 数据库 / FTP：**不创建**

> 老版宝塔没有 Tab 分类，是「网站 → 添加站点」里把 PHP 版本选为**纯静态**——效果一样。
> 提交后宝塔会在站点根目录生成两个默认占位文件：`index.html`、`404.html`。

---

## 4. 上传构建产物

1. 本机先把 `dist` 压缩成 zip（资源管理器右键 → 发送到压缩文件夹即可，**压缩 dist 文件夹本身**）；
2. 宝塔 → **文件** → 进入 `/www/wwwroot/resume-creation.wtyw.asia`；
3. **删除宝塔默认的 `index.html` 和 `404.html`**（占位页会盖住我们的页面）；
4. 上传 `dist.zip` → 右键 **解压**；
5. ⚠️ **检查层级**：解压后必须是下面这个结构（`index.html` 直接在站点根目录）：

   ```
   /www/wwwroot/resume-creation.wtyw.asia/
   ├── index.html          ← 必须在这一层
   ├── assets/
   ├── fonts/
   ├── robots.txt
   ├── sitemap.xml
   └── og-image.png
   ```

   如果解压出了多一层 `dist/`（变成 `/dist/index.html`），把 `dist` 里面的内容剪切到根目录再删空壳。

## 5. SPA 路由回退（必做，否则 `/editor` 刷新 404）

`/editor` 是 React 前端路由，服务器上并不存在这个文件，需要把未知路径统一回退给 `index.html`：

宝塔 → 网站 → 该站点 **设置 → 伪静态**，粘贴以下内容并保存：

```nginx
location / {
  try_files $uri $uri/ /index.html;
}
```

保存后宝塔会自动重载 Nginx。

**自测**：浏览器直接打开 `http://resume-creation.wtyw.asia/editor` 并刷新（F5）——能正常进入编辑器就说明配对了；报 404 就是这步没生效。

## 6. 性能配置（建议做，5 分钟）

### 6.1 静态资源长缓存

站点 **设置 → 配置文件**（左侧菜单项），按 **Ctrl+End** 跳到文件末尾，把下面两段贴在**最后一个 `}`（server 块的闭合大括号）之前**，然后保存（宝塔自动重载 Nginx）。注意 `^~` 前缀，它保证优先级压过面板自带的 js/css 缓存规则：

```nginx
    # PDF 导出用中文字体：内容不变，永久缓存
    location ^~ /fonts/ {
      add_header Cache-Control "public, max-age=31536000, immutable";
      access_log off;
    }

    # 带 hash 的 JS/CSS：内容变名字就变，同样永久缓存
    location ^~ /assets/ {
      add_header Cache-Control "public, max-age=31536000, immutable";
      access_log off;
    }
```

> 注意区分：**伪静态**（§5 的 try_files）贴在左侧「伪静态」菜单里；这两段缓存贴在「配置文件」末尾。别贴混。

### 6.2 Gzip（可选，字体文件提速明显）

字体子集单个 2~7MB，开启 gzip 后传输量减半。宝塔 → 软件商店 → Nginx → 设置 → **配置修改**，找到 `gzip` 段，在 `gzip_types` 一行末尾（引号内）追加：

```
font/ttf font/otf application/json
```

即形如：

```nginx
gzip_types text/plain text/css application/javascript application/x-javascript text/xml application/xml application/json font/ttf font/otf;
```

保存重载（宝塔默认已开 `gzip on`，这里只是把字体类型补进压缩清单）。

### 6.3 默认文档

站点 **设置 → 默认文档**：确认 `index.html` 在列表里且排最前（纯静态站没有 `index.php`）。

## 7. HTTPS（建议做）

站点 **设置 → SSL**：

1. 选 **Let's Encrypt** → 勾选 `resume-creation.wtyw.asia` → 文件验证 → **申请**（宝塔自动配续期）；
2. 申请成功后打开 **强制 HTTPS** 开关。

完成后访问 `https://resume-creation.wtyw.asia` 应自动从 http 跳转 https。
（备选：阿里云控制台申领免费证书（DV），下载 Nginx 格式，在 SSL → 其他证书里粘贴。）

## 9. 以后怎么更新版本

```bash
# 1. 本地改完代码后重新构建
cd /d/code/resume-creation
npm run build
# 2. 重新压缩 dist 为 dist.zip
```

1. 宝塔 → 文件 → 站点根目录：**先删旧的 `assets/` 文件夹**（旧 hash 文件会越积越多），再删 `index.html`；
2. 上传新的 `dist.zip` → 解压（`fonts/`、`robots.txt` 等直接覆盖即可；只有重新跑过 `npm run fonts` 才需要替换 fonts）；
3. 浏览器 Ctrl+F5 强刷验证。

> 进阶（当前规模不必要）：上 GitHub Actions 自动构建 + rsync/宝塔 API 自动发布。手动上传 5 分钟内搞定，先用最简单的方式。

## 10. 常见问题排查

| 症状 | 原因与处理 |
|---|---|
| 刷新 `/editor` 报 404 | 第 5 步伪静态没保存生效；或 Nginx 未重载（宝塔首页 → 重载配置） |
| 打开站点是宝塔默认欢迎页 | 第 4 步没删默认 `index.html`，或解压多了层级 |
| 导出 PDF 提示「内嵌字体文件缺失」 | `public/fonts` 没进站点根目录（上传漏了或层级不对），Network 里会看到 `/fonts/...` 404 |
| 整站 502 / 打不开 | 服务器安全组没放行 80/443（§1），或 Nginx 没在运行 |
| HTTPS 证书申请失败 | 域名解析未生效，或 80 端口没放行（Let's Encrypt 文件验证走 80） |
| 面板/网站偶尔卡死 | 检查是否曾在服务器上跑过 `npm install`/`build`（2G 内存扛不住，用 swap 兜底或放弃服务器构建） |
| 想临时关站 | 宝塔站点列表 → 停止站点即可，无需删文件 |

## 11. 上线后的 SEO/GEO 动作（可选但建议，30 分钟）

代码里已固化 `https://resume-creation.wtyw.asia` 为站点地址（`index.html` 的 canonical/og:url、`public/robots.txt` 的 Sitemap 行、`public/sitemap.xml`）。上线后：

1. **Google Search Console**（search.google.com/search-console）→ 添加资源（域名前缀 `https://resume-creation.wtyw.asia`）→ 左侧「站点地图」提交 `https://resume-creation.wtyw.asia/sitemap.xml`；
2. **Bing 站长工具**（bing.com/webmasters）→ 同样提交 sitemap。Copilot 的引用来自 Bing 索引，这步对 GEO 直接有效；
3. **结构化数据验证**：打开 `https://search.google.com/test/rich-results` 输入首页网址，应识别出 WebApplication / FAQPage 两类富结果无报错；
4. **AI 引擎抽查**（上线两周后）：分别问 ChatGPT / Perplexity「免费无水印的中文在线简历工具有哪些」，看是否被引用；不被引用很正常，新域名冷启动需要时间——持续更新 + 内容扎实（首页 FAQ 已按 GEO 原则写好）是唯一的加速器；
5. 若未来**更换域名**：需同步改三处——`index.html`（canonical、og:url、JSON-LD 里的 URL）、`public/robots.txt`（Sitemap 行）、`public/sitemap.xml`（loc），重新构建上传即可。
